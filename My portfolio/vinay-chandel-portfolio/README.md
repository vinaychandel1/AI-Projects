# Vinay Chandel - Professional Portfolio Website

An Awwwards-level, cinematic, immersive personal portfolio website built for **Vinay Chandel** (Integration Consultant & Technical Lead).

## Features
- **Cinematic Preloader & Custom Cursor**: Interactive cursor and loading screen with smooth GSAP animations.
- **Glassmorphism Design**: Modern futuristic dark theme with Tailwind CSS blur effects and glowing gradients.
- **Interactive Integration Network**: SVG node network background animations representing hybrid integration architecture.
- **GSAP ScrollTrigger**: Scroll-driven storytelling, reveal animations, and professional timeline sections.
- **Full Professional Resume Coverage**: Highlighting experience at HCLTech, TCS, Polaris, Galaxy POD, RFT Integration, IBM webMethods, and Azure.

## Local Running & Deployment
1. Open `vinay-chandel-portfolio/index.html` in any modern web browser or serve via local static server:
   ```bash
   npx serve .
   ```
2. Deploy to GitHub Pages or Netlify by pointing the root directory or publishing the `vinay-chandel-portfolio` folder.
